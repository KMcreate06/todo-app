# To-Do List

Application de liste de tâches en React + Vite.

## Fonctionnalités

- Ajouter, cocher, modifier (double-clic ou ✏️) et supprimer des tâches
- Filtres : toutes / à faire / terminées, « tout cocher » et « effacer les terminées »
- Sauvegarde automatique dans le `localStorage` du navigateur
- Mode sombre (suit la préférence système par défaut, choix mémorisé)

## Lancer le projet

```bash
npm install
npm run dev      # serveur de dev
npm run build    # build de production dans dist/
npm run preview  # prévisualiser le build
```
